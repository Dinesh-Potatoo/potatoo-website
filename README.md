# Potatoo website

Landing page for Potatoo – home-cooked dog food in Chennai.

## Edit
- WhatsApp number, greeting and menu dishes: the `<script>` block near the bottom of `index.html`.
- Logo: `assets/potatoo-logo.png`.

## Host on GitHub Pages
1. Create a new repository on GitHub (e.g. `potatoo-website`) and push these files.
2. In the repo: Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`.
3. Your site will be live at `https://<your-username>.github.io/potatoo-website/` in a minute or two.
